# Workflow Studio

Automated System Workflow Generator & Documentation Builder.

## Stack
- Next.js 14 App Router + TypeScript
- Tailwind CSS
- Framer Motion
- Mermaid
- ASP.NET Core Web API (planned integration)
- SQL Server (planned integration)

## Development

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Current implementation
The workspace includes six workflow generators, editable rows, Mermaid source editing, undo/redo, responsive layout, project metadata, and animated UI foundations.

## Roadmap
- ASP.NET Core API + SQL Server persistence
- Debounced autosave and sync status
- Real Mermaid canvas rendering with zoom/pan/fullscreen
- CSV/XLSX import and column mapping
- PNG/SVG/DOCX/PDF exports
- Project list and multi-project CRUD
- Full validation and keyboard/drag-reorder UX
- Production build and browser QA
